# 潮汐方舟 — 系统设计 v0.2

> 承接《设计文档》v0.1（已实现的核心循环）和《故事》v0.2。本文件定义 v0.2 要加的系统、数据结构和初始数值。
> 数值都是**初始值**，试玩后再调；公式集中放在 `game.js` 顶部常量里，方便调参。

## 1. 设计原则（眼镜约束）

1. **四个键打完全程**：上 / 下 / 确认 / 返回。不加新按键，二选一用「确认 / 返回」表达。
2. **一眼看懂**：主界面永远回答三件事——今晚危险吗、我该做什么（目标）、还缺什么。
3. **短局**：一天 60 秒；剧情弹窗暂停时间；随时可摘眼镜（自动存档）。
4. **不堆系统**：每章只引入 1–2 个新东西，每个设施只有一个效果、一个数字。

## 2. 核心循环（v0.2）

```
          ┌──── 海域选择（近海 / 残骸带 / 沉城）
出海打捞 ─┤
          └──── 捞到：资源 · 宝箱 · 剧情物（集装箱/采样舱/图纸/门禁卡）
   │
   ▼
建造与升级 ──> 设施（8 种）──> 被动产出 / 打捞加成 / 防御
   │
   ▼
居民入住（剧情）──> 永久加成 + 每日多喝 1 份水
   │
   ▼
夜间结算：饮水 → 夜间事件（平静 / 风暴潮夜 / 海盗夜 / 商人日）
   │
   ▼
章节目标完成 ──> 剧情 ──> 下一章解锁
```

## 3. 章节与目标系统（v0.2 的主骨架）

替代 v0.1 零散的剧情节点：游戏进程由「当前章节 + 目标清单」驱动。

```js
// 数据（game.js）
CHAPTERS = [
  { id: 1, title: '第一口淡水', goals: [
      { id: 'filter2',  text: '升级过滤器',     done: s => s.lv.filter >= 2 },
      { id: 'rivet',    text: '救起漂流者',     done: s => s.npc.rivet },
      { id: 'shelter2', text: '庇护所升到 Lv2', done: s => s.lv.shelter >= 2 },
    ], onEnter: [], onDone: ['ch2'] },
  ...
]
// 状态
s.chapter = 1          // 当前章节
s.npc = { rivet: true } // 已入住居民
s.flags = {}           // 剧情物、一次性事件
s.seen / s.queue       // 已实现：剧情节点去重与排队
```

- 每次按键和每次 tick 后检查当前章目标；全部完成 → 播放章末剧情 → `chapter++` → 播放下一章开场剧情。
- 主界面加一行**目标**：显示第一个未完成目标，如 `目标 · 救起漂流者 (1/3)`。
- 章节只解锁内容，不锁玩法：玩家可以超前升级，但设施要等章节解锁才出现在建造列表里。
- 剧情触发保持现有规则：排队，只在没有弹窗、不在打捞、不在撬锁时弹出。

## 7. 海域

出海时如果解锁了 2 个以上海域，先弹出海域选择（上下选，确认出发）；只有近海时直接出海。

| 海域 | 解锁 | 准星速度 | 物品宽度 | 掉落（权重） | 危险 |
|---|---|---|---|---|---|
| 近海 | — | 55+4·天（上限 110） | 11−0.3·天（最小 5） | 废料45 水瓶18 滤芯14 宝箱11 电鳗5 海藻7 漂流瓶3 | 无 |
| 残骸带 | 拖船 Lv1 | ×1.15 | ×0.9 | 废料50 滤芯18 宝箱14 电鳗8 **图纸碎片**5* 漂流瓶3 巨鲨5 | 巨鲨：扯断一钩、−5 耐久 |
| 沉城 | 拖船 Lv2 | ×1.3 | ×0.8 | 废料40 滤芯20 宝箱(铁/金)18 电鳗10 **门禁卡**5* 漂流瓶3 巨鲨4 水母3 | 巨鲨；水母：本趟准星 −30% |

\* 剧情物只在需要时出现，拿齐后从掉落表移除；在对应章节，第 3 次进入该海域时必定出现一次，避免卡关。

**剧情漂流物**：集装箱（铆钉）、采样舱（珊瑚）、小舢板（小锅）、断气管（气泡）。条件满足时，下一次出海必定刷出一件，宽度 ×1.5，带特殊标记 `!`。

## 9. 夜间结算

每天结束按顺序处理：

1. **饮水**：`3 + floor(天/4) + 居民数 − (小锅?1:0)`；缺水每份 −6 耐久（不变）。
2. **被动产出**：寄居蟹吊机、章鱼工坊。
3. **夜间事件**（每晚只有一种）：

| 夜晚 | 规则 |
|---|---|
| 平静夜 | 无伤害 |
| 风暴潮夜 | 从第三章起，每 3 晚一次（第 3、6、9…天）。伤害 = `max(0, 潮力 − 防御)`；潮力 = `10 + 4·天`；防御 = `12·庇护所 + 10·藤壶 + 5·铁梁 + 5·锈锚`。第三章之前不刮风暴（新手保护）。 |
| 海盗夜 | 第六章起，每 3 晚一次，与风暴错开（风暴 +1 天）。战力 = `30 + 3·天`。确认＝打：防御 ≥ 战力则胜；败则 −20 耐久、−30% 废料。返回＝交：−50% 废料，下次战力 +10%。击退一次后结束。 |
| 商人日 | 第四章起，每 3 天上午来访（不是夜间事件）：主界面出现「秤砣」菜单项，当天有效。 |

4. **预报**：主界面风暴行改成显示下一个危险夜：`▲ 2 晚后风暴潮 −14` / `▲ 今晚海盗` / `○ 3 晚内平静`。

示例（未计居民）：第 15 天风暴潮力 70；Lv5 + 藤壶 1 = 70 → 0 伤害。第 30 天潮力 130；Lv7 + 藤壶 3 + 铁梁 + 锈锚 = 124 → −6。

## 11. 结局与自由模式

- 庇护所 Lv8 触发终章；二选一（确认＝广播 / 返回＝交出），结果写入 `s.ending`。
- 结局后：不再死于风暴（耐久最低 1）；广播结局每天 +#10，交出结局每日饮水为 0。
- 第二幕钩子（深蓝计划第二阶段）只在弹窗里出现，v0.2 不实现第二幕。

## 14. 实现分期

| 阶段 | 内容 | 依赖素材 |
|---|---|---|
| M1 | 章节 / 目标系统、主界面目标行、序章与第一–三章剧情、居民（铆钉/珊瑚/小锅）、剧情漂流物、新的风暴规则与预报、藤壶装甲 | 已有线稿 + 角色线稿 |

**M2 实现时定下的细节**（已写进 `game.js`）：
- 第四章目标加了「庇护所升到 Lv5」，让铁梁（随 outpost 入住）落在第四章。
- 商人货单按天轮换（`(天 + i) mod 5`），不用存档保存；每笔当天限 1 次。
- 海盗夜要求进入第六章至少 2 天后，第一次来袭前留出准备时间。
- 残骸带废料每件 +3；第 3 趟起，只要还缺图纸，每趟必出一片。
- 海龟拖船 Lv2（沉城）在第七章前锁定；Lv8 庇护所额外需要 ◇10。
- 章鱼工坊耗电 0.05/s·级，算进过滤器的同一电力预算。

**M3 实现时定下的细节**（已写进 `game.js`）：
- 庇护所 Lv8 在第八章前锁定（「方舟 · 第八章」）：方舟要装潮汐引擎，先下潜实验室。旧的「方舟建成」弹窗改成剧情 ark → confront → 二选一。
- 二选一不记入 seen：存档时弹窗丢失，读档后重新弹出。返回键在二选一弹窗上表示「交出」，不会退出游戏。
- 气泡的断气管只在沉城出现；门禁卡要等气泡入住后才进掉落表，第 3 趟沉城起必出。
- 沉城废料每件 +5；沉城宝箱只有铁箱（75%）和金箱。
- 发光水母：钩中后本趟准星速度 ×0.7（占一钩）。
- 实验室是海域列表里的一项（拿到门禁卡后出现，下潜一次后消失），不打捞，只播放剧情。林博士、潮生不算居民，不喝水。
- 结局后进入第 9 个章节「第一幕完 · 自由漂流」，不弹章节卡；目标行显示结局效果。
- 庇护所 Lv7 弹出白砂的来信（industry）。
- 存档 v2：v1 存档照常读取；v0.1 存档按庇护所 / 发电机等级推断章节（最高第四章），补上之前章节的居民，相关剧情记为已看过。
- 章鱼夜：拖船 Lv2（沉城解锁）后，每个风暴潮夜伤害 ×1.2（四舍五入），预报数字已包含；结算行写「风暴潮+章鱼」，第一次触发时弹出「巨型章鱼」剧情（lore-04）。
- 漂流瓶：三个海域的掉落表都有，权重 3（不算稀有物，信标不加成）。钩中后打捞屏显示一句话，按 `flags.letters` 计数在 10 条里轮换；返航汇总只记「漂流瓶」，无资源、无弹窗。插画 salvage-18。
